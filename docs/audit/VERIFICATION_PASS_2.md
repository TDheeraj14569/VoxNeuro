A later audit identified additional defects, which are tracked in `docs/audit/DEFECT_REPAIR_LOG.md`; current verification is recorded in `docs/testing/VERIFICATION_REPORT.md` and `docs/audit/VERIFICATION_PASS_3.md`.

**Reviewer role:** separate read-only code reviewer who did not implement the changes. The reviewer inspected the code afresh and reproduced the two findings below; the same reviewer rechecked their corrections. This is independent source review, not independent clinical validation or a second dataset cohort.

## Findings and corrective actions

### P1 — Manifest integrity flags could be forged while labels disagreed

**Finding:** `validate_manifest()` trusted `label_match=True`; a manifest could say `class_label=HC`, `source_label=PD`, and point to `PD_AH` while passing the earlier check. The reviewer reproduced this.

**Correction:** `src/voxneuro/dataset/validation.py` now requires source label/sample key/age/sex/source fields for integrity audits, explicitly normalizes source diagnosis text, recomputes agreement with the class folder, and checks source/participant ID against the audio filename. `tests/unit/test_dataset.py` includes a tampered-label regression.

**Recheck:** Reviewer confirmed the prior reproduction now returns a class/source/folder mismatch. The regression test passes. The final full suite grew to 99 passed after coverage review added additional helper-module tests.

### P2 — UCI inspection required the UAMS dataset

**Finding:** The CLI always called `inspect_uams()` before `inspect_uci()`, so a UCI-only download failed before UCI could be inspected.

**Correction:** `scripts/inspect_dataset.py` now has `--dataset all|uams|uci`. README documents the independent command. A temporary-root test confirms `--dataset uci` calls no UAMS code and succeeds with no UAMS files present.

**Recheck:** Reviewer confirmed the selected UCI mode skips UAMS. The real CLI completed against the local UCI source; current summary is 756 rows, 755 columns, 252 participants, and one exact duplicate row. Focused tests passed.
